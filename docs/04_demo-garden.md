# 04 — 예시 정원 구경하기 (첫 방문 체험)

> 상태: **승인 (2026-11-25) · M1~M3 완료 (출품 소개문 사용자 확정 2026-11-26) — docs/04 종료** · 부록: 다크 계절감

## 배경

하입소문 서비스 공모전(hypevibe.co.kr/contest, 2026-11-25 공고 확인)의 심사는
**이용자 투표(12/1~12/9, 별점 + 리뷰를 둘 다 남겨야 1표) + 운영진 내부 심사**이며 세부 기준·비율은
비공개다. 평가자는 처음 들어온 사람이고, 여러 출품작을 돌며 몇 분씩 써 본다.

지금 Study Garden의 첫 방문 화면은 빈 정원("정원이 첫 씨앗을 기다리고 있어요")이고, 첫 식물을
보려면 **최소 30분**(`DURATION_OPTIONS = [30, 45, 60, 90]`)을 집중해야 한다. 데이터는 기기별
localStorage라 모든 평가자가 빈 정원에서 시작한다. 즉 평가자 대부분은 이 앱의 핵심(공부 시간이
정원으로 자라는 것)을 **보지 못한 채** 별점을 매긴다.

이 문서는 빈 정원에서 **한 번 눌러 10초 안에 "한 달 가꾼 정원"을 구경**하게 하는 기능만 다룬다.

## 목표 / 비목표

**목표**

1. 빈 정원(세션 0개)일 때 홈 정원 아래에 **"예시 정원 구경하기"** 텍스트 버튼을 보여 준다.
2. 누르면 시트가 열리고, **한 달을 가꾼 예시 정원**을 읽기 전용으로 보여 준다:
   - 정원 SVG (새싹·잎·꽃·나무 4단계 + 과목 꽃색 + 달성 꽃이 모두 보이는 구성)
   - 한 줄 캡션 (예: "어느 대학생의 한 달 · 28그루 · 꽃 7송이")
   - 숫자 3개 (가꾼 시간 · 공부한 날 · 목표 꽃) + 과목 범례
   - 맨 아래 **"내 정원 가꾸러 가기"** 버튼 → 시트를 닫는다.
3. 예시는 **사용자 데이터에 아무것도 쓰지 않는다** (store·localStorage 무변경).

**비목표** (범위 확장은 여기서 막는다)

- 짧은 맛보기 세션(B안)·집중 시간 선택지 변경 없음.
- 예시 데이터로 기록·숲 페이지를 돌아다니는 "데모 모드" 없음 — 시트 하나로 끝난다.
- 예시 정원 안에서 계절 바꿔 보기 없음 (계절은 지금처럼 `html[data-season]` 하나 — 시트도 현재 계절로 보인다).
- 예시에서 PNG 저장·공유 없음.
- 세션이 1개라도 있는 사용자에게는 버튼을 보이지 않는다 (설정 등 다른 진입점 없음).
- 온보딩 튜토리얼·코치마크 없음.

## 계약

### 새 순수 함수 — `lib/demo.ts` (런타임 import 금지 규칙 그대로: 다른 모듈은 `import type`만)

```ts
export interface DemoGarden {
  year: number; month: number          // 예시가 속한 달 (getGardenPlants에 그대로 넘김)
  sessions: Session[]                   // 고정 시드 — 오늘 날짜와 무관
  subjects: Subject[]                   // 4개 (종 0·1·2·3)
  achieved: string[]                    // 달성 꽃 날짜 'YYYY-MM-DD'
}
export function demoGarden(): DemoGarden
```

- **오늘 날짜에 의존하지 않는다.** 투표가 12/1~12/9라 "이번 달 1일~오늘"로 만들면 12월 초에는
  예시가 거의 비어 버린다. 예시는 **고정된 30일짜리 달**(예: 2026년 11월)로 만들고, 그 year/month로
  `getGardenPlants(sessions, year, month, …)`·`getGoalFlowers(achieved)`를 호출한다.
  성장 단계는 "심은 뒤 그달 누적 시간"만으로 정해지므로(lib/garden.ts) 결과가 결정적이다.
- 시드 구성은 readme-shots.mjs의 연출 시드(하루 ~30분, 4과목, 7일 휴식, 달성 7일)를 출발점으로
  측정 1에서 확정한다.
- 결정적 출력이라 하이드레이션 안전 (렌더 중 `Date.now()`/`Math.random()` 없음).

### UI

- `components/home/DemoGardenSheet.tsx` — 기존 `ui/Sheet` 안에 `Garden`(기존 컴포넌트, props만 다름)을 렌더.
  `Garden`의 `growing`·`seedWaiting`은 false, `ambient`는 기본값.
- `app/page.tsx` — `hydrated && sessions.length === 0`일 때만 진입 버튼. 시트 열림 상태는 페이지 로컬 state
  (ui-store에 넣지 않는다 — 저장할 필요 없음).
- 새 색·그림자 없음 — 기존 토큰만.

### 기존 계약과의 관계

- 데이터 모델·localStorage 키 변경 없음. docs/03 계약과 충돌 없음.
- `Garden`·`getGardenPlants`·`getGoalFlowers` 시그니처 변경 없음.

3. **10초 목표** — 첫 로드부터 시트 안 정원이 보이기까지 클릭 1번, 시간은 배포판에서 측정해 기록.

- **일정** — 접수 마감 11/30 23:59, 운영진 검수 후 12/1 공개. M3가 11/28을 넘기면 **이 기능 없이(C안) 제출**하고
  서두른 배포를 하지 않는다. → M1·M2 승인 게이트를 하루 안에 돌려야 한다.
- **투표 기간 배포 동결 (12/1~12/9)** — 이 기능도 12/1 이후에는 고치지 않는다(장애 수정만, 승인 후).
  → 버그가 남으면 투표 기간 내내 남는다는 뜻이므로 M3 검증을 배포판에서 한다.

  → 제철디자인상을 노린다면 출품 소개 이미지(README 스크린샷)로 보완한다. 기능으로 풀지 않는다(비목표).
- **기록·숲 페이지는 여전히 빈 화면** — 평가자가 그쪽으로 가면 빈 상태를 본다. → 이번 범위 밖, 출품 소개문의 체험 순서로 홈 → 예시 정원을 안내한다.
